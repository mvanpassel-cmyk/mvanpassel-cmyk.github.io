// ABOUT

Origin. VEKTOR NOX started as a late-night radio experiment: what if a techno set was scored like a space voyage, launch, drift, contact, re-entry?

Sound. Rolling basslines, analogue arpeggios, field recordings from empty places, and the occasional transmission that should not be there.

Live rig. Two decks, one modular case, a tape echo that has seen too much, and a strict no-phones-on-the-bridge policy.

Mission. Long sets. Low light. A room that forgets what time it is.
